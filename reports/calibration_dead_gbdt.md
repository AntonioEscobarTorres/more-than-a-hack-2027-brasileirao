# Calibration of the dead-ball evidence, GBDT variant (F3-08)

Generated by `modeling.calibration.dead_gbdt` from the degraded IDSSE masters (external data only; the provided match is never read). Every number below comes from a model that did not see the match it is computed on (leave one match out), except the scenarios of the model `all`. The F3-04 logistic models of the reference file are evaluated on exactly the same rows. Nothing is chosen here: the adoption is decided by F2-06.

- model: `HistGradientBoostingClassifier` (`max_iter=300`, `learning_rate=0.05`, `max_leaf_nodes=31`, `min_samples_leaf=500`, `l2_regularization=1.0`, `early_stopping=False`, `random_state=0`), scikit-learn `1.5.2`
- features (35): `out_of_pitch`, `db_gap_kind`, `db_still_frac`, `db_mean_speed`, `db_fast_in_pitch`, `gap_length`, `d_touchline`, `d_goalline`, `still_past_mean_25`, `still_fut_mean_25`, `still_fut_minus_past_25`, `speed_past_mean_25`, `speed_fut_mean_25`, `speed_fut_minus_past_25`, `d_touchline_cent_min_25`, `d_goalline_cent_min_25`, `out_of_pitch_cent_max_25`, `still_past_mean_50`, `still_fut_mean_50`, `still_fut_minus_past_50`, `speed_past_mean_50`, `speed_fut_mean_50`, `speed_fut_minus_past_50`, `d_touchline_cent_min_50`, `d_goalline_cent_min_50`, `out_of_pitch_cent_max_50`, `still_past_mean_75`, `still_fut_mean_75`, `still_fut_minus_past_75`, `speed_past_mean_75`, `speed_fut_mean_75`, `speed_fut_minus_past_75`, `d_touchline_cent_min_75`, `d_goalline_cent_min_75`, `out_of_pitch_cent_max_75`
- no imputation, no indicator: the model routes NaN natively; `db_ball_rest`, `ball_speed` and the windowed share of `ball_observed` are never features
- `d_fit = decision_function(x) − logit(pi_D)`, `pi_D` of the model's own training rows; `d = clip(d_fit + dead_tag_prior, ±12)`
