# Technical report

The final technical report (task F5-07) is
**[`brasileirao.pdf`](brasileirao.pdf)**, built from **[`brasileirao.tex`](brasileirao.tex)**.

This file used to hold the working draft, filled in by each front during the project. It was
replaced by the LaTeX report, which supersedes it: the draft was out of date in places (for example,
it listed the broadcast tracking as dropped, while the fused broadcast ball was adopted in D-024).
The draft remains in the git history.

To rebuild the PDF: `pdflatex brasileirao.tex` twice (or upload the `.tex` to Overleaf). Every
number in the report comes from external data (degraded IDSSE); no value derived from the provided
match and no public-window score appears in it.
